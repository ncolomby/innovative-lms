# innovative-lms

## Workflow policies
- **Backlog → Ready:** has acceptance criteria, priority, estimate, owner; no unfinished dependencies.
- **Ready → In Progress:** pull only if In Progress is under its limit (2). Check Review first.
- **In Progress → Review:** all acceptance criteria met; comment summarizing the work.
- **Review → Done:** acceptance criteria checked off and approval comment added.
- **Blocked items:** add the `blocked` label, comment the cause, owner, and next action. Blocked items still count toward WIP.
- **Urgent requests:** move to top of Ready; pull when a slot opens — don't interrupt work in progress.
